# Reel playbook

## Job definition

A Reel is not automatically a product advertisement. Select one primary job:

- create desire / memory;
- demonstrate material, craft or outcome;
- answer a buyer question;
- build trust through process or people;
- convert a qualified action such as a DM, catalogue request, appointment or store visit;
- translate a timely cultural format into a genuinely relevant brand moment.

One Reel can have secondary benefits, but its edit and CTA should serve one primary job.

## A 15-second proof-led structure

This is a flexible timing model, not a mandatory formula.

1. **0–2 seconds: visual question.** Motion or a tactile close-up begins immediately. Avoid a static title card unless the title itself is the hook.
2. **2–6 seconds: specific proof.** Show the actual detail, use, process, transformation, or buyer problem.
3. **6–11 seconds: payoff / range / human relevance.** Reveal the product, colour choice, fit, scale, story, or result.
4. **11–13 seconds: buyer reason.** One verified, specific line or visual proof—not a list of adjectives.
5. **13–15 seconds: clean CTA and branded end.** Protect the end card; do not crowd it. The action should match sales operations.

Some films should slow down, remove voiceover, or end before 15 seconds. The point is pace with purpose, not filling a timer.

## Choose one of these spines

### Tactile reveal

Macro movement → closer proof → colour/range reveal → intentional product frame → DM action.

### Process payoff

Raw input / hand action → satisfying process → finished result → specific fact → CTA.

### Buyer question

Show the question visually → answer with evidence → use/selection cue → CTA. Best for FAQs repeatedly seen in DMs/comments.

### Editorial desire

One distinctive environment or movement → product teased in details → reveal → quiet memory line → profile/DM CTA. Best when the brief is brand-building rather than price-led conversion.

### Trend translation

Only use after passing four checks: current enough for the target region/account, commercially usable, relevant to the audience, and capable of showing real product proof. If any fails, select an original audio or another spine.

### Founder / maker point of view

Face, hands, place, or voice establishes a real human stake → evidence → product → conversational CTA. Avoid a scripted sales lecture.

## Voice, music and captions

- Voiceover should add what visuals cannot: a personal observation, a buyer insight, a tiny story, or a decisive detail.
- For Indian / diaspora audiences, Hinglish voiceover with clear English captions can work well when it matches the actual brand; never make it a default caricature.
- Record or generate multiple emotional reads privately and choose one. If using TTS, only use a user-authorised provider and an approved voice.
- Captions are not decorative noise. Style them in the type system, segment them meaningfully, and place them away from the hero content.
- Use music at a supportive mix level. The final upload screen, account type and geography decide whether a sound is available or commercially usable.

## Publishing pack

The final Reel needs more than an MP4:

- cover and grid preview;
- caption with a compelling first line and line breaks;
- natural SEO terms, not keyword stuffing;
- alt text;
- audio note and trend-search query if no rights-cleared audio can be embedded;
- primary CTA and proposed DM keyword;
- suggested response to that keyword;
- posting hypothesis, not a universal “best time” claim;
- one success metric and a follow-up test.

## Textile example: what real proof looks like

For fabric, use supplied footage/photos to show exactly what can be defended: weave, stripe/motif, palette, drape, edge, hand interaction, reverse side, scale, pattern alignment, apparel implication, packaging, or assortment. Do not turn a swatch into an invented garment, colourway, price, or composition via generated imagery. If a styled shirt helps explain potential use, label it as concept/styling support unless the actual fabric/product is proven in the frame.
