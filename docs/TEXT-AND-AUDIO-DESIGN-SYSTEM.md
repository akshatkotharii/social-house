# Text and audio design system

This is a production gate, not an aesthetic menu. Text, sound and motion are designed from the actual footage after its source-material ceiling is known.

## 1. Decide whether text belongs at all

No text is valid when real product movement, process or texture carries the idea. Add on-frame text only when it answers one current buyer question:

- What am I seeing?
- Why does this matter to me?
- What specific action can I take?

Delete decorative copy, generic claims and duplicate narration. Captions and post copy can carry information that would obscure a proof shot.

## 2. Write against the shot

Before choosing a font, make a shot map. For every proposed line, record:

- frame range and purpose;
- protected proof region;
- stable negative-space region across the full hold, not one sampled frame;
- background luminance and dominant colour;
- text role: label, buyer insight, spoken subtitle or CTA;
- entry/exit event: action, cut, reveal, colour change or intentional hold.

If no safe region remains stable, use a text-free shot, move copy to a different shot, or build a deliberate graphic composition. Never add a translucent slab merely to rescue unreadable text.

## 3. Brand type system

Define a small system per brand before production:

| Role | Job | Rules |
| --- | --- | --- |
| Headline | One remembered thought or decision | One family, one weight range, short lines, no generic adjectives |
| Detail | Clarifies visible proof | Supporting family only if needed; smaller but phone-readable |
| Subtitle | Carries spoken words | Calm sans-serif, phrase-level timing, never automatically styled karaoke text |
| CTA | One real next action | Direct, visually separate, late enough that proof has earned it |
| Cover | Makes grid tap-worthy | A separate layout, not a frame grab with leftover captions |

Use at most two families. Start with the brand's owned fonts. If none exist, make a temporary restrained pairing explicit and test it; do not call a serif/sans combination “premium” by default.

## 4. Contrast, spacing and placement

- Choose text colour from measured frame contrast, not brand palette alone.
- Start with generous edge clearance (roughly 10–15% when no platform preview is available), then adjust against the actual Instagram/Facebook UI and shot. This is not a universal safe-zone guarantee.
- Check the entire text interval at phone size. A clear first frame can become unreadable once fabric, hand or camera moves behind it.
- Use stroke/shadow/backdrop only when needed for legibility. Treat it as a visual decision, never a universal subtitle preset.
- Keep headline line height, tracking, margins and alignment consistent inside one asset. Break rules only for a stated visual reason.
- Keep product detail unobstructed. For fabric, weave, edge, motif, colour and hand contact outrank copy placement.

## 5. Text motion

Motion must respond to picture or soundtrack:

- hard cut: stable cut-on text, no decorative entrance;
- hand/fabric pass: reveal text from that movement when legible;
- colour/range reveal: one quiet label may appear after viewer has seen the shade;
- static editorial shot: restrained opacity or position motion can carry energy;
- voice subtitle: appear by phrase, slightly ahead of speech only when natural.

Default duration is short and readable, not “0.3–0.5 seconds” for every asset. Avoid typewriter, bounce, glitch, kinetic text, emoji and sound-pop patterns unless format, brand and reference mechanics justify them.

## 6. Audio design and mix ledger

For spoken Reels, caption timing must follow the final voice take and any cut map. Group phrases by meaning and reading time; choose emphasis for a verified buyer-relevant turn, not every word by default. A post-render speech-to-caption sync check is useful but cannot replace listening or correct Hinglish/product vocabulary. Runtime procedure: [speech, captions and emphasis](../skills/social-house/references/caption-sync.md).

Create an audio ledger before assembly:

| Track | Source/rights | Start/end | Role | Level and fades | Cut cue |
| --- | --- | --- | --- | --- | --- |
| Voice | approved human or commercially permitted provider | | story | | |
| Music | owned/licensed/platform-only | | emotional arc | | |
| Natural sound | real source | | proof/texture | | |
| SFX | licensed/self-made | | one edit cue | | |

Do not stack audio because tracks exist. One precise tactile sound or a clean silence can outperform continuous music. Music must have identifiable edit points; voice, music, natural sound and endcard audio need deliberate fades/crossfades and must not collide.

Suggested technical targets are a starting point, not proof of quality: preserve voice intelligibility, leave peak headroom, avoid clipping, and normalise only after creative mix decisions. Never substitute meter readings for listening.

## 7. Mandatory release review

Watch the final render from start to end:

1. with sound on using headphones;
2. with sound off at phone size;
3. after checking key frames through every text interval;
4. after checking every audio transition, cut, cue, voice handoff and endcard.

Reject if any second has accidental overlap, abrupt level jump, masked voice, late cue, clipped peak, unreadable text, generic copy, text over proof, or an animation unrelated to picture. If audio cannot be heard in the review environment, status cannot exceed `creative-ready, audio unverified`.

## 8. Textile defaults

For textile Reels, begin with proof, not a title. Favour texture, hand action, edge, range, light and process. Text may be absent for first seconds. If copy appears, it must name visible material/range/use or provide a genuine buyer action. Generated imagery is supporting context only and must not carry product-specific text claims.
