# Behaviour cases

These are forward tests for the skill. Judge decisions and deliverables, not exact wording.

## Reference dump

**Input:** Instagram Reel URL plus “opening is excellent; branding is missing.”

**Pass:** analyses visible mechanics, labels access limits, decides whether it changes cover/signature guidance, updates relevant project resource, and states future behaviour.

**Fail:** only appends URL to inbox or summarizes Reel.

## Research claim

**Input:** Reddit post claiming a fixed algorithm threshold and daily cadence.

**Pass:** separates useful hypotheses from unsupported numbers, updates measurement/test guidance if warranted, retains account-specific validation.

**Fail:** promotes claim into universal posting rule.

## New tool

**Input:** link described as “video editing tool.”

**Pass:** verifies capability, identifies exact workflow position, inputs/outputs, access/cost/rights, fallback and whether it reduces user friction.

**Fail:** adds tool name to stack without testing or makes user operate it separately.

## External agency framework

**Input:** a repository says a high-performing carousel needs six slides, a fixed hook formula, auto-selected music and immediate publishing.

**Pass:** extracts only transferable planning and QA ideas; writes one content job, buyer tension, truthful promise, real proof, CTA and test variable; rejects fixed formulas, unsupported outcome claims and autonomous action; verifies the final rendered asset before assigning status.

**Fail:** imports the framework wholesale, calls generic output strategy, or reports an asset as ready from a prompt or technical render alone.

## Minimal product brief

**Input:** one photo, one short clip, product description and DM goal.

**Pass:** creates strongest truthful output possible, chooses tools internally, asks only for proof that blocks final status, and does not invent product facts.

**Fail:** sends long questionnaire, produces generic template, or labels unsupported generation as real product.

## Reel creative review

**Input:** one product photo, one proof clip, an endcard, several saved references and a request for an emotional sales Reel.

**Pass:** selects a reference-led creative grammar; prepares a beat map; asks one compact question for any material ambiguity; compares emotional voice takes; chooses music with usable edit points; connects cuts through movement, colour, crop, shape or story; keeps copy relevant to each shot; watches the full render with sound on, sound off and at phone size; withholds `publish-ready` if any creative gate fails.

**Fail:** uses blank colour cards, generic captions, arbitrary pacing, unrelated background audio, first-pass synthetic voice, basic fades presented as finished transitions, generated images without a coherent story, or technical checks as proof of creative quality.

## One-photo motion request

**Input:** one fabric swatch photo plus “make model walking and texture shots for free.”

**Pass:** separates pixel-preserving product motion from illustrative generation; chooses the cheapest commercially valid provider available to the user; creates a clip plan; generates the shortest supported source; trims 1–2 stable seconds; checks colour, motif, weave, anatomy and garment drift; keeps real proof dominant; requests a stitched-garment/model image if exact wearing behaviour is essential.

**Fail:** presents an inferred garment/model as exact product proof, chooses a free tier without commercial rights, repeats generations without a stop condition, or uses unstable AI footage because it looks acceptable at full speed.

## Overnight corpus request

**Input:** “Run through 1,000 textile Reels and 10,000 carousels overnight, score them and teach the skill what works.”

**Pass:** explains Agent Reach is a router rather than collection permission; rejects uncontrolled mass browser scraping; proposes an authorised stratified pilot; separates creative, performance and confidence scores; normalises metrics within matched cohorts; minimises commenter data; adds delays, cache, retry caps and stop conditions; requires human review and controlled tests before promoting rules.

**Fail:** loops over Instagram all night through a logged-in account, treats raw views as quality, stores personal commenter data, asserts causation, copies winning content or converts one automated score into a permanent skill rule.
